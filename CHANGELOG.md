# История версий

Номер версии задаётся в одном месте — `res/version.h`. Перед выпуском: `tests\run_tests.ps1` должен пройти без ошибок.

## 0.14 beta — 14.10.2026

- «Чтение RAM»: один график, но линия — среднее по 8 соседним точкам (256 Б), а разброс замеров показан полупрозрачной полосой. Линии больше не сливаются в «забор».
- «Запись RAM»: 4 панели во всю ширину, по одной на размер блока, с общим масштабом по Y. В каждой две линии: сплошная — запись в обход кэша (NT), пунктир — обычная запись через кэш. Линии без сглаживания — видны все колебания. Таблица — 4 строки, NT и через кэш в одной строке.
- Многопоток: порог «буфер мерил бы кэш» поднят с 2×L3 до 4×L3 — при лимите памяти 512 МБ точка на 2 потока показывала 109 % теоретического пика.
- Галочка «Фильтр (сглаж.)» заменена на «Сырые точки»: на «Чтении RAM» показывает замеры как есть, без полосы.
- Подсказка под курсором показывает среднее и разброс в этой точке.

## 0.13 beta — 14.10.2026

- В заголовке окна и в свойствах exe осталось только название и версия.
- Новый текст «О программе» и вступление README: раздел «Особенности» вместо сравнительной таблицы.
- Режим «4 МБ» подписан по сути: «4 МБ — в пределах L3».
- Тёмная тема для всего окна: свои кнопки, вкладки, списки, галочки и строка состояния с полосой хода тестов; тёмные графики, таблицы и вкладка «Система». На Windows 10 1809+ тёмные заголовок окна и полосы прокрутки.
- В «О программе» указан контакт для связи.
- Исправлено: в «Многопотоке» при малом объёме свободной памяти первые точки мерили L3 вместо ОЗУ (больше 100 % теоретического пика). Теперь точки, где суммарный буфер меньше 2×L3, пропускаются, и об этом выводится примечание.

## 0.12 beta — 14.10.2026

- Под таблицами в интерфейсе (и в сохранённых PNG) больше нет длинных пояснений — только предупреждения, выделенные оранжевым: частота ядра менялась во время теста, включён режим «4 МБ», памяти хватило не на все потоки.
- Пояснения ко всем вкладкам перенесены в README, раздел «Как читать результаты».
- Скриншоты окна программы в README (docs/screens), примеры в examples/i5-12500H пересняты на 0.12.

## 0.11 beta — 14.10.2026

Исправления по итогам тестов на эмуляции 17 конфигураций и стресс-тестов.

- Старые BIOS с DDR/DDR2: частота, записанная в МГц ровно на границе стандарта (DDR2-400 вместо DDR2-800), теперь пересчитывается в МТ/с.
- Core Ultra: у L3 показывалось неверное число ядер («на 10 яд.» вместо 14), теперь считается по маске ядер, а не по потокам.
- Если Windows не отдала топологию процессора — программа не падает, а считает каждый логический CPU отдельным ядром и пишет об этом в отчёте.
- Двухсокетные серверы: каналы памяти различаются по NODE/CPU/SOCKET в названиях слотов (было 4 канала вместо 8).
- Многопоток: скорость = общий объём / общее время окна. Раньше поток, запущенный планировщиком с опозданием, мерил «свой» короткий отрезок, и сумма завышалась.
- Лимит памяти процесса (job object, песочницы): размеры буферов учитывают лимит; поток, которому не хватило памяти, пропускается вместо падения (была ошибка доступа к памяти); в отчёте пометка «памяти хватило на N потоков из M».
- `--auto` создаёт вложенные папки.
- Добавлены тесты: эмуляция железа (`tests/emu.*`), фаззинг SMBIOS, автоматический набор проверок `tests/run_tests.ps1`.
- Версия задаётся в `res/version.h` (exe, окно, отчёты, манифест).
